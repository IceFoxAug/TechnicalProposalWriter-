# Technical Proposal Writer

技术标书写作专家，根据标书模板和参考论文自动生成研究现状、研究内容等章节。

## 触发条件

用户需要撰写或修改技术标书时使用，涉及 docx 模板解析、PDF 论文内容提取、标书章节生成等场景。

## 核心能力
- 解析Word标书模板，提取写作指示和格式要求
- 从参考论文中提取研究现状和引用文献
- 按照模板要求重新组织论文内容
- 支持增量写作：可指定只写某个章节（如3.4节）
- 保持引用一致性：使用原论文的引用编号
- **引用控制**：用户可选择是否在正文中标注引用、是否生成参考文献列表
- **图表溯源**：插入参考论文的图片或表格时，自动标注对应参考文献及原文位置
- **仅真实插图**：除概览性技术路线图外，不自行绘制任何图片，只使用参考文献中的真实插图
- **文字优先**：尽量用文字表述替代表格，尤其涉及多方案对比时优先使用叙述性文字

## 图片使用规则（重要）

### 基本原则
1. **除开篇技术路线图外，不自行绘制任何图片**。所有插入图片必须是所给参考文献中真实存在的插图
2. 每张图片插入时必须标注：文献名称 + 原文章节 + 原图编号
3. 图片编号采用标书自身的编号体系（如图3.5-1、图3.5.2-1），但必须注明原论文出处

### 参考论文图片无法提取时的处理
当参考论文为扫描版PDF、图片无法提取时：
1. **从题注和上下文推知图片内容**：阅读图片的题注（如"图2-5 储能系统成本构成"）和周围的正文描述
2. **判断是否插入**：根据推知的内容判断该图片对标书是否有价值
   - 有价值 → 在文档中标注插入点，格式：`【插入图片：文献名，第X章 图X-Y 题注内容】`
   - 无价值 → 跳过，用文字概述相关结论即可
3. **插入点的文字说明**：在插入点附近用文字概述该图的核心信息，使文档即使暂未插入图片也可阅读

## 使用方式

### 基本用法
```
写标书，模板是 template.docx，参考论文有 paper1.pdf 和 paper2.pdf
```

### 指定章节写作
```
只写标书的3.4节，模板用 template.docx，参考论文用 paper1.pdf
```

### 引用偏好设置（重要）
用户指定写作部分后，**必须主动询问**：
1. 是否需要在正文中标注引用编号（如[1]、[2,3]）？
2. 是否需要在文末生成参考文献列表？
3. 引用编号以模板已有编号为准还是从论文中提取？
4. **预期篇幅是多少页？**（模板如有要求以模板为准，否则询问用户）

示例询问：
```
请问：
① 正文中标注引用编号？
② 在章节末尾生成参考文献列表？
③ 引用编号以哪个为准？（模板/论文/自动编号）
④ 预期篇幅多少页？（模板要求30页 / 您指定页数）
```

### 篇幅控制
- 用户指定预期页数后，据此控制生成内容的详细程度
- 每页按约800汉字（纯文字）估算
- **图片占页计算**：每张插入的图片按常规尺寸（约14cm宽×10cm高）估算，约占1/4~1/3页
- 含有公式的段落密度略低，每页约600~700汉字+公式
- 最终输出时汇报实际字符数和预估页数

### 多章节写作
```
写标书的3.1、3.4和研究内容部分
```

### 增量修改
```
在现有的标书.docx基础上，重写3.5节，参考新的论文 new_paper.pdf
```

## 参数说明
- **模板文件**：Word格式(.docx)，包含写作指示（用【】或{{}}标记）和格式要求
- **参考论文**：PDF格式，由pdf-reader skill解析
- **目标章节**：可指定章节编号（如3.4）、标题（如"研究现状"）或多个章节
- **基础文档**（可选）：增量模式时指定要修改的现有标书
- **include_citations**（新增）：是否在正文中标注引用编号，默认询问用户
- **include_reference_list**（新增）：是否在文末生成参考文献列表，默认询问用户

## 协作关系

本 skill 依赖 `pdf-reader` skill。当用户说"写标书"时，按以下协作流程执行：

### 协作流程
1. **首先调用 pdf-reader** — 解析用户提供的所有 PDF 参考论文，提取完整文本内容
2. **然后调用本 skill** — 将 pdf-reader 的解析结果（论文文本）作为 `papers_data` 传入
3. **本 skill 生成标书** — 根据模板要求组织论文内容，生成 Word 文档

### 执行步骤
当用户发出"写标书"指令时：
1. 识别用户提供的 PDF 论文文件 → 逐篇调用 pdf-reader 解析
2. 识别用户提供的 docx 模板文件 → 路径传给本 skill
3. 将 PDF 解析结果组装为 `papers_data` 格式：
   ```python
   [{
       'filename': 'paper1.pdf',
       'content': 'pdf-reader解析出的完整文本',
       'metadata': {'title': '...', 'authors': '...'}
   }]
   ```
4. 实例化 `TechnicalProposalWriter` 并调用 `write_proposal()` 生成标书

## 工作流程
1. 解析模板 → 提取写作指示和格式
2. 分析论文 → pdf-reader 提供文本内容
3. 提取引用 → 从论文中提取参考文献
4. 用户确认 → 展示将写作的章节
5. 生成内容 → 按章节逐一生成
6. 输出文档 → 保存为Word文件

## 输出
- Word文档(.docx)，包含生成的标书内容
- 保持模板格式，公式和图表来自参考论文
- 引用使用原论文编号
- **图表溯源标注**：每个插入的图表/表格下方自动标注来源信息
  - 格式：`（数据来源：参考文献[X]，第Y章 图Z-W）` 或 `（图片来源：参考文献[X]，第Y章 表Z-W）`
  - 对于无法确定具体位置的图片，标注为：`（图片来源：参考文献[X]）`
  - 对于综合多个来源的数据，标注为：`（数据来源：综合参考文献[X]、[Y]）`

## 图表溯源规范
当在生成的文档中需要插入、引用或描述参考论文中的图片、表格或数据时：
1. **必须标注来源**：每张图/表下方添加来源标注行
2. **标注信息包含**：文献名称 + 原文章节位置 + 原图/表编号
3. **标注格式**：宋体小五（9pt），灰色，居中，置于图表下方
4. **标注示例**：
   - `图3.5-1 储能系统成本构成（图片来源：祝元恺，面向多能耦合发电系统的规模化储能技术经济评估研究，浙江大学博士学位论文，2024，第2.3节 图2-5）`
   - `表3.5-2 三类储能参数对比（数据来源：高明非，综合能源系统多元储能优化配置及协同运行研究，华北电力大学博士学位论文，2024，第4章 表4-1）`

## 表格使用规范
1. **优先使用文字叙述**：涉及方案对比、参数罗列、性能比较等场景时，优先采用叙述性文字而非表格
2. **表格仅用于必要场景**：仅当数据项超过5项且每一项都有明确数值时，方考虑使用表格
3. **对比场景的文字化处理**：将"表X 方案对比"改写为分段叙述，每段以一个方案为主线展开
4. **参数罗列的文字化处理**：将表格形式的参数列表改写为自然段落，如"电化学储能的单位功率成本为800~1200元/kW，单位容量成本为600~800元/kWh，循环寿命5000~8000次…；飞轮储能的对应参数分别为…"

## 图片不可提取时的处理流程
```
参考论文PDF → 尝试提取图片
    ├── 可提取 → 插入图片 + 标注来源（文献名+章节+图号）
    └── 不可提取（扫描版）→ 阅读题注和上下文
            ├── 内容有价值 → 标注插入点：【插入图片：文献名，第X章 图X-Y，题注："..."】+ 文字概述核心信息
            └── 内容可替代 → 用文字直接概述结论，不标注插入点
```
